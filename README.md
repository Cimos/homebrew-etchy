# Homebrew tap for etchy

[etchy](https://github.com/Cimos/etchy) is a visual and geometric diff tool for
PCB Gerber, drill and PDF revisions. This tap installs the desktop viewer on
Apple Silicon Macs, and puts the `etchy` command-line tool on your PATH.

```sh
brew install --cask cimos/etchy/etchy
```

The app is not code-signed yet, so macOS blocks the first launch. Open
System Settings > Privacy & Security and click "Open Anyway".

The standalone command-line archives and the Windows and Linux installers are on the
[etchy releases page](https://github.com/Cimos/etchy/releases).
